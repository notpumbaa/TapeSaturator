# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report them privately via GitHub instead:
**Security** tab → **Report a vulnerability**
(https://github.com/notpumbaa/TapeSaturator/security/advisories/new).

Please include:
- what you found and where (file, function, plugin format, host/DAW),
- steps to reproduce,
- the TapeSaturator version and your OS.

You can expect a first response within a few days. Fixes are released as a new version on the
[Releases](https://github.com/notpumbaa/TapeSaturator/releases) page.

## Supported versions

Only the latest release receives fixes.
